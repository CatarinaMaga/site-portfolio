# Portfólio — Catarina Magalhães

Site profissional de Catarina Magalhães, analista e desenvolvedora de sistemas. O conteúdo apresenta os serviços de forma simples para pessoas que não são da área de tecnologia.

## Site publicado

[catarina-magalhaes-portfolio.vercel.app](https://catarina-magalhaes-portfolio.vercel.app/)

## Principais características

- HTML semântico e estrutura acessível;
- layout responsivo para computadores, tablets e celulares;
- conteúdo em linguagem clara para clientes e empresas;
- metadados para mecanismos de busca e compartilhamento em redes sociais;
- dados estruturados com Schema.org;
- `robots.txt` e `sitemap.xml`;
- contatos por e-mail, LinkedIn, GitHub e WhatsApp.

## Tecnologias

- React 19;
- TypeScript;
- vinext e Vite;
- CSS responsivo;
- Vercel e Sites para hospedagem.

## Executar localmente

É necessário ter Node.js 22.13 ou superior.

```bash
npm install
npm run dev
```

Para validar a versão de produção:

```bash
npm test
```

## Estrutura principal

- `app/page.tsx`: conteúdo e HTML semântico;
- `app/globals.css`: identidade visual e responsividade;
- `app/layout.tsx`: metadados de SEO e compartilhamento;
- `app/robots.ts` e `app/sitemap.ts`: orientação para buscadores;
- `public/`: logo e imagem de compartilhamento;
- `vercel/`: versão estática publicada na Vercel.
